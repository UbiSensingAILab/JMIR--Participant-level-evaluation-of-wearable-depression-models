# Reproducing the JMIR revision analyses

`scripts/revision/run_all_revision.py` reruns every revision result in order, from the repo root:

```bash
python3 scripts/revision/run_all_revision.py              # everything, using cached MOMENT embeddings
python3 scripts/revision/run_all_revision.py --moment     # first regenerate MOMENT embeddings (.venv311)
python3 scripts/revision/run_all_revision.py --from final_fl.py   # resume at a step
```

Logs: `results/revision/logs/<step>.log`. Outputs: `results/revision/` (aggregates) and `results/revision/final/` (manuscript package). Participant-level predictions go to `research_datasets/revision_cache/` (gitignored, research data).

## Environments

| Env | Used for | Key packages |
|---|---|---|
| `.venv-psyche-d-fl-mlp` | every analysis step | lightgbm 4.7, xgboost 3.4.1, scikit-learn 1.7.1, torch 2.14, flwr 1.38, matplotlib |
| `.venv311` | MOMENT embeddings only (`--moment`) | momentfm, torch |

Every step runs in its own process with `OMP_NUM_THREADS=1`. On this Mac, torch and LightGBM/XGBoost in one process segfault or deadlock. For the same reason, FedAvg runs in a separate torch-only worker (`p2_fl_mlp.py`).

## Run order and approximate runtime (Apple silicon laptop, 2026-10-16)

| # | Step | What it produces | Time |
|---|---|---|---|
| 0 | `--moment`: `psyche_d_moment_small.py sequences` / `embed`; `hrv_phq9_protocol_stage06b_moment_embed.py`; `resilient_protocol_stage06a_moment_embed.py` | MOMENT-1-small embeddings (cached in research_datasets) | ~15-20 min |
| 1 | `p0_audit.py` | Phase 0 inventory, CI level, feature groups | ~2 min |
| 2 | `p1_cv.py`, `p1_temporal.py`, `p1_holdout.py` | Phase 1 CV arms, temporal split, held-out test | ~8 min |
| 3 | `p2_fl_rerun.py`, `p2_fl_noniid.py`, `p2_mb_selected.py` | Phase 2 FL reruns, Dirichlet non-IID, MB at the selected round | ~2 min |
| 4 | `p3_small_datasets.py` | HRV leakage CIs, HRV MOMENT reruns, small-dataset calibration | ~3.5 min |
| 5 | `r_tier1_cv.py` | R1-R5 (timing ablation, forecast, permutation importance, severity) | ~11 min |
| 6 | `r_tier1_split.py` | R6 development-only selection and test, R7 calibration | ~3 min |
| 7 | `r_tier1_fl.py` | R8 (TreeAvg eta 0.05 primary) | <1 min |
| 8 | `final_fl.py` | T2-T5: FL on 152 and 41 inputs, local-only, birth-year non-IID, communication (as specified) | ~2 min |
| 9 | `FL_VARY_SEED=1 final_fl.py` | same, with a different XGBoost seed per round (`*_seedvary`) | ~2 min |
| 10 | `final_outcome_calib.py` | T6 outcome sensitivity, T9 calibration and operating points | ~1 min |
| 11 | `final_package.py` | T1 manuscript state, T8 label-shuffle provenance, `final/` tables, FINAL_NUMBERS, figures | <1 min |

Total: about 31 min without `--moment` (full run on 2026-10-16: 30.7 min; every CSV byte-identical to the first run, JSON files identical apart from runtime fields).

Not regenerated by the runner (narrative files, written by hand from the outputs): `final/METHODS_NOTES.md`, `final/CLAIM_CHANGES.md`, `final/PLAIN_SUMMARY.md`, `SUMMARY.md`.

Inputs that must exist:
- `research_datasets/old/psyche_d/anon_processed_df.parquet`
- `scripts/psyche_d_fedavg_vs_fedtree_split_cache.pkl`
- the HRV and PHQ-9 and RESILIENT protocol caches in `scripts/.cache`
- the saved original FL result JSONs in `scripts/` (used for the reproduction checks)
